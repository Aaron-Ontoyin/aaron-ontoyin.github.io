Aaron Ontoyin Yin

I work on decision-making systems that can explain themselves. My published work uses large language models to induce interpretable decision models — trees, rule ensembles, executable code — from unstructured data, and to benchmark them. I want to extend this to sequential decisions: agents that learn what to ask, when to act, and when to stop.

02Research

Direction How should an agent decide which costly signal to gather next, and when to stop, when its policy must remain inspectable? Can LLM-induced rule sets serve as interpretable policies rather than static classifiers? What does verifiable reasoning look like when the decision unfolds over time?

Interpretable decision-making with LLMs

Instead of asking a language model for an answer, we ask it for a decision structure: a tree split, a yes/no question, a probabilistic rule, a piece of executable code. The structure is then fitted and validated statistically, so every prediction has a path a person can read.

I co-invented GPTree and implement much of this line of work in think-reason-learn.

GPTree · GPT-HTree · RRF · LLM-AR · Verifiable reasoning · CoFEE

Benchmarks and data

Rare-outcome prediction needs shared, leak-resistant data. I built the founder-profile dataset the group's papers run on and contributed to VCBench, the first standardized benchmark for founder-success prediction.

VCBench · Rare-event prediction

Applied ML for physical and industrial systems

Before Vela: a digital-twin planner for directional drilling and an LSTM kick-prediction model (about 89% recall) for UMaT's Drillbotics entries, a machine-learning layer for real-time well monitoring, and an AI-powered smart-metering capstone. This is where my interest in learning for physical systems comes from.

05Software

think-reason-learn

An open-source, LLM-native machine-learning framework: scikit-learn-style estimators whose splits, rules, and questions are proposed by a language model and then fitted and validated like any other model. It unifies GPTree, Random Rule Forest, Reasoned Rule Mining, and Policy Induction under one interface. MIT licensed.

I started the library and remain a core contributor.
